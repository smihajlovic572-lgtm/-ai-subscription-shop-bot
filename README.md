# Telegram-магазин AI-подписок

Готовый бот на Python 3.11+ и aiogram 3: каталог GPT/Claude и других сервисов,
заказы с ручной проверкой оплаты, профиль клиента и админ-панель.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# заполните BOT_TOKEN, ADMIN_IDS, PAYMENT_DETAILS
python bot.py
```

`ADMIN_IDS` — Telegram ID администраторов через запятую. Узнать ID можно у
`@userinfobot`. База `shop.db` и начальный каталог создаются автоматически.

## Что умеет

- каталог и карточки товаров;
- создание заказа и отправка чека/подтверждения;
- уведомление всех администраторов;
- подтверждение и отклонение заказа;
- сообщение с данными подписки покупателю;
- профиль и история заказов;
- добавление/включение/отключение товаров;
- статистика и рассылка;
- премиум-эмодзи в HTML-сообщениях и custom emoji icons в кнопках.

Перед продажами укажите юридическую информацию, правила возврата и используйте
только законные способы предоставления подписок. Для автоматической оплаты
подключите официальный платёжный провайдер и проверяйте webhook на сервере.
